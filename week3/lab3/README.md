# Lab 3: Process Management and OS Interaction

## Module

ST5003CMD Operating Systems, Security, And Networks

## Lab Overview

This lab explores how C programs interact with the Linux operating system. It covers process execution, process identification, exit status, standard input/output, and conditional program termination.

## Tasks

- Task 1: The Long-Running Process
- Task 2: Process Identity (PID and PPID)
- Task 3: Exit Codes and OS Feedback
- Task 4: Standard I/O Streams
- Task 5: Conditional Execution and Termination

## Source Files

- task1_alive.c
- task2_identity.c
- task3_exit.c
- task4_input.c
- task5_control.c

## Main Concepts

- Process execution and monitoring
- PID and PPID
- Exit codes and OS feedback
- Standard input and output
- Conditional execution and termination
